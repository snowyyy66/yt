# Развёртывание фронтенда на Vercel

Vercel здесь отдаёт статический интерфейс и проксирует API к отдельному HTTPS-серверу. FastAPI, PostgreSQL, S3-хранилище, Redis и FFmpeg worker нужно запустить на контейнерном хостинге с постоянными дисками и фоновыми процессами. Compose-стек проекта можно развернуть на Ubuntu по инструкции в корневом README.

## Подготовка

1. Разверни Compose-стек на сервере и настрой DNS с HTTPS для API, например `https://api.example.com`.
2. Убедись, что API отвечает по `/health`, Swagger открывается по `/docs`, а `S3_PUBLIC_ENDPOINT` указывает на доступный по HTTPS S3 endpoint.
3. В `vercel.json` замени `https://api.example.com` на публичный адрес своего API во всех четырёх прокси-маршрутах.
4. Импортируй репозиторий в Vercel. Framework Preset оставь `Other`; Build Command и Output Directory уже заданы в `vercel.json`.

Сборка кладёт `index.html` в корень статического вывода, а файлы CSS/JS — в `/static/`, сохраняя пути из исходного FastAPI-приложения. Запусти её локально командой `python scripts/build_vercel.py`, чтобы проверить структуру вывода.

## Переменные и сервисы

Секреты остаются на API-сервере в его `.env`; переменные Vercel для текущего статического фронтенда не нужны. Не добавляй `.env` в Git или настройки Vercel.

На API-сервере задай production значения `DATABASE_URL`, `APP_SECRET`, `S3_ENDPOINT`, `S3_PUBLIC_ENDPOINT`, `S3_BUCKET`, `MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD`, `S3_REGION`, `REDIS_URL` и `VIDEO_WORKER_ENABLED=true`. PostgreSQL и S3-провайдер должны принимать защищённые подключения с API и worker. Worker должен работать постоянно и иметь FFmpeg.

## Ограничения

- Vercel не запускает Docker Compose и постоянный Redis/FFmpeg worker как часть этого статического деплоя.
- Сейчас браузер загружает видео через API. Запросы к внешнему origin через Vercel ограничены прокси-таймаутом в 120 секунд; кроме того, если API перенести в Vercel Function, там действует лимит тела запроса 4,5 МБ. Для крупных и долгих загрузок нужен прямой браузерный upload в S3 по короткоживущей подписанной ссылке; это отдельная доработка приложения.
- Видео раздаются напрямую из S3 по короткоживущим подписанным URL, поэтому S3 endpoint должен быть доступен браузеру, а bucket CORS должен разрешать домен Vercel для загрузки и чтения объектов.

Для локального полного стека и фоновой обработки продолжай использовать `bash deploy.sh`; Vercel заменяет только слой доставки фронтенда.
