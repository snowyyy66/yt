# Видосфера

Пародийный видеохостинг с привычной лентой, поиском и плеером. Здесь ролики обещают раскрыть секрет успеха, а комментарии напоминают, что интернет всё ещё интернет.

## Запуск на Ubuntu

Требуются Docker Engine с Compose plugin и Python 3.12+ для генерации случайных секретов. Из корня репозитория:

```sh
bash deploy.sh
```

Скрипт создаёт `.env` со случайными секретами и запускает API, PostgreSQL, Silo (S3-хранилище, совместимое с MinIO) и Redis. API: <http://localhost:8000>, Swagger: <http://localhost:8000/docs>, консоль хранилища: <http://localhost:9001>.

Для локальной разработки скопируй `.env.example` в `.env` и выполни `docker compose up --build -d`.

## Фронтенд на Vercel

Vercel раздаёт только статический фронтенд и проксирует API; база, S3-хранилище и FFmpeg worker должны работать на отдельном сервере. Подготовка и ограничения описаны в [docs/vercel.md](docs/vercel.md).

## Демо-данные

После запуска выполни `docker compose exec app python -m scripts.seed_demo`. Пароль для демо-аккаунтов хранится в `.env` как `DEMO_PASSWORD`; скрипт не выводит его. Демо-входы: `viewer@vidosphera.example.com`, `moderator@vidosphera.example.com`, `admin@vidosphera.example.com`, `creator@vidosphera.example.com`. Seed создаёт короткий тестовый ролик через FFmpeg и сохраняет его в MinIO вместе с превью, а также добавляет демо-аккаунты и комментарии.

## Проверки

```sh
python -m pip install -e '.[test]'
python -m pytest
```

Тесты проверяют HTTP-контракт, регистрацию и вход, запрет анонимных комментариев, загрузку в S3-совместимое хранилище, проверку частного доступа, подписку и запрет доступа пользователя к очереди модерации.

## Устройство

- FastAPI обслуживает API и статический интерфейс, Swagger доступен на `/docs`.
- PostgreSQL хранит аккаунты, комментарии, лайки, видео, разрешения на приватный доступ, подписки и жалобы.
- MinIO хранит загруженные файлы. API выдаёт ссылку на скачивание/просмотр на пять минут после проверки приватного доступа.
- Redis ставит загрузки в очередь. Worker на FFmpeg нормализует видео в MP4, делает миниатюру и переводит ролик из `processing` в `ready`. Адаптивные варианты HLS/DASH пока не создаются.
- Роли: `user`, `moderator`, `admin`. Повышение роли выполняется оператором базы данных.

План и схема описаны в `docs/`. Коммитить `.env` нельзя.
